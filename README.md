# RESCENE 2048

걸그룹 리센느(RESCENE)의 **비공식 비수익 팬게임**입니다.

- 플레이: https://rescene-fan-game.github.io/rescene-2048/
- 원작 2048 규칙에 멤버별 시기 이미지를 더한 게임입니다.
- 이 저장소에는 배포용 WebGL 빌드만 있습니다.
